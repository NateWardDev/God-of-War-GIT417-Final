# God of War Norse Saga Website

A responsive, media-rich fan website dedicated to the **Norse Mythology era** of
the God of War franchise, developed as the final course project for **GIT 417**.

## 📌 Project Overview

This website serves as a comprehensive digital experience exploring the entire
Norse saga, including _God of War (2018)_, _God of War Ragnarök_, and the
_Valhalla_ expansion. The site features deep dives into the lore, major
characters, and specifically honors **Laufey the Just (Faye)**, whose hidden
choices set the entire narrative arc in motion.

Built from scratch using modern web development techniques, the site showcases
semantic HTML structure, advanced responsive layout design, and clean, native
CSS styling.

## 🚀 Features

- **The Norse Chronology:** Dedicated tracking of Kratos and Atreus's journey
  across all nine realms, from the 2018 awakening to the conclusion of the
  Valhalla DLC.
- **The Legend of Laufey:** A specialized lore section focusing on Laufey
  (Faye), her role as a Guardian of the Jötnar, her rebellion against the Aesir,
  and her profound legacy left for her family.
- **Modern Semantic HTML:** Built with clean, accessible, and
  search-engine-friendly markup structures.
- **Native CSS Nesting:** Utilizes modern CSS native nesting to maintain
  scalable and organized stylesheets without relying on external preprocessors
  like Sass.
- **Fluid Responsive Design:** Implements modern CSS Grid layouts, Flexbox
  structures, and nested media queries to ensure seamless experiences across
  mobile, tablet, and desktop viewports.
- **Media Integration:** Incorporates game trailers, cinematic clips, and
  promotional imagery celebrating the franchise.

## 🛠️ Built With

- **HTML5** — Structural layout
- **CSS3** — Native nesting, Flexbox, CSS Grid, and media queries
- **Vanilla JavaScript** — Interactivity and dynamic behaviors

## 📅 Development Log

### 1. Design

I began by planning the website's visual design and layout around the God of War
Norse saga. I considered how to organize the content, present the game's lore
and characters, and create a visual identity that reflected the atmosphere of
the franchise. I also planned the layouts with both desktop and mobile users in
mind.

### 2. Desktop Development

After establishing the design, I developed the desktop version of the website. I
implemented the HTML structure, CSS styling, and JavaScript functionality,
including the gallery popups and shopping cart. I also set up CSS variables to
support the website's light and dark modes.

### 3. Mobile Development

Once the desktop version was established, I adapted the website for mobile
devices. I adjusted layouts, styling, and responsive behavior to accommodate
smaller screens and ensure that the content and interactive elements remained
usable across different viewport sizes.

### 4. Testing and Refinement

After developing the desktop and mobile versions, I tested the website's
appearance and functionality. I checked the interactive features, examined the
theme switching behavior, and addressed issues discovered during testing. I used
online programming resources, including Stack Overflow and other forums, when
researching solutions to development problems.
