### God of War Norse Saga Website

A responsive, media-rich fan website dedicated to the **Norse Mythology era** of
the God of War franchise, developed as the final course project for **GIT
417**. 

### 📌 Project Overview

This website serves as a comprehensive digital experience exploring the entire
Norse saga, including _God of War (2018)_, _God of War Ragnarök_, and the
_Valhalla_ expansion. The site features deep-dives into the lore, major
characters, and specifically honors **Laufey the Just (Faye)**, whose hidden
choices set the entire narrative arc in motion. Built from scratch using modern
web development techniques, the site showcases semantic HTML structure, advanced
responsive layout design, and clean, native CSS styling. 

### 🚀 Features

- **The Norse Chronology:** Dedicated tracking of Kratos and Atreus's journey
  across all nine realms from the 2018 awakening to the conclusion of the
  Valhalla DLC.
- **The Legend of Laufey:** A specialized lore section focusing on Laufey
  (Faye), her role as a Guardian of the Jötnar, her rebellion against the Aesir,
  and her profound legacy left for her family.
- **Modern Semantic HTML:** Built with clean, accessible, and
  search-engine-friendly markup structures.
- **Native CSS Nesting:** Utilizes modern CSS native nesting architectures to
  maintain scalable and organized stylesheets without relying on external
  preprocessors like Sass.
- **Fluid Responsive Design:** Implements modern CSS grid layouts, flexbox
  structures, and nested media queries ensuring seamless experiences across
  mobile, tablet, and desktop viewports.
- **Media Integration:** Built to host and display optimized game trailers,
  cinematic clips, and promotional imagery celebrating the franchise.

### 🛠️ Built With

- **HTML5** (Structural Layout)
- **CSS3** (Native Nesting, Flexbox, CSS Grid, Media Queries)
- **Vanilla JavaScript** (Interactivity & Dynamic Behaviors)
